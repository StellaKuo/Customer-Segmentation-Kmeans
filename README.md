# 🛍️ Customer Segmentation using K-Means

## 📌 Project Overview

本專案使用 **K-Means Clustering** 進行消費者分群，並透過 **Elbow Method** 選擇適合的群集數量，分析不同客群的消費特徵。

## 🛠 Technologies

- Python
- Pandas
- Matplotlib
- Scikit-learn

## 📈 Result

透過 **Elbow Method** 分析不同 K 值的 Inertia，選擇 **K = 7** 建立最終 K-Means 模型，並利用 Income 與 Spending 視覺化不同消費者群體的分布。
